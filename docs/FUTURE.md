# GridNudge: Future Scope (Non-Core / Post-Hackathon)

The following items are out of the immediate hackathon build scope and are documented here per Section 1.6 of `AGENTS.md`:

1. **Deep / Offline Reinforcement Learning**:
   - CQL, IQL, Decision Transformer, or Multi-Agent RL.
   - Core GridNudge relies on sample-efficient contextual bandits (Linear Thompson Sampling) with explicit safety constraints and causal reward design.

2. **Causal Forest / Heterogeneous Treatment Effect Estimators**:
   - Double Machine Learning (DML) / Causal Forests for complex continuous treatments.

3. **Graph Neural Networks (GNNs)**:
   - GNN power flow analysis across distribution feeder topology.

4. **Real-world Charger Control / V2G**:
   - Direct OCPP 2.0.1 / ISO 15118 protocol integration for bidirectional charging (V2G) and automated smart charging profiles.

5. **Fleet-Validated Battery Lifespan Models**:
   - Comprehensive electrochemical degradation tracking based on multi-year telematics from real Indian EV fleets.

6. **Mobile Applications**:
   - Native iOS / Android client applications for drivers.
